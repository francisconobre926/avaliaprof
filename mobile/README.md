# Mobile — GoHome Android

App Android nativa (prioridade do MVP).

## 🛠️ Stack proposta

- **Linguagem:** Kotlin
- **UI:** Jetpack Compose
- **Arquitectura:** MVVM + Clean Architecture
- **Injecção de dependências:** Hilt
- **Networking:** Retrofit + OkHttp
- **Base de dados local:** Room
- **Chat em tempo real:** Socket.io client
- **Mapas:** Google Maps SDK
- **Push:** Firebase Cloud Messaging
- **Análise:** Firebase Analytics + Crashlytics

## 📋 Requisitos mínimos

- Android SDK 24+ (Android 7.0 Nougat)
- Testar em: Android 7, 10, 12, 14
