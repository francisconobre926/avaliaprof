# Mobile — GoHome App

App mobile do GoHome, construída com React Native + Expo.

Foco inicial: **Android** (prioridade do MVP).
Fase seguinte: **iOS** (mesma base de código).

## 🛠️ Stack

- **Framework:** React Native
- **Runtime/tooling:** Expo (SDK mais recente estável)
- **Linguagem:** TypeScript
- **Navegação:** React Navigation
- **Estado:** Zustand ou Redux Toolkit (a decidir na implementação)
- **Networking:** Axios ou Fetch API
- **Chat em tempo real:** Socket.io client
- **Mapas:** react-native-maps (Google Maps)
- **Push:** expo-notifications + Firebase Cloud Messaging
- **Storage local:** AsyncStorage / MMKV
- **Formulários:** React Hook Form
- **Validação:** Zod ou Yup
- **Análise:** Firebase Analytics + Crashlytics (via Expo)

## 📋 Requisitos mínimos

- Android 7.0+ (SDK 24+)
- Node.js 20+ para desenvolvimento
- Expo CLI

## 🚀 Setup (a definir)

> Instruções detalhadas serão adicionadas quando o projecto for iniciado.

Passos previstos:
1. Instalar Node.js e Expo CLI
2. Clonar o repo
3. `npm install`
4. `npx expo start`
5. Correr no emulador Android ou dispositivo físico via Expo Go
