# Admin — GoHome Painel Administrativo

Painel web para a equipa LGT gerir a plataforma.

## 🛠️ Stack proposta

- **Framework:** Next.js 14+ (App Router)
- **Linguagem:** TypeScript
- **UI:** shadcn/ui + Tailwind CSS
- **Estado:** Zustand ou React Query
- **Autenticação:** JWT + 2FA obrigatório

## 📋 Funcionalidades

Ver Secção 32 do DDR:

- Dashboard geral com métricas
- Gestão de utilizadores (procuradores, anunciantes)
- Moderação de anúncios (aprovar, rejeitar, suspender)
- Gestão de denúncias
- Gestão de conversas denunciadas
- Gestão de categorias
- Gestão de preços/taxas por cidade
- Gestão de promoções por cidade (activar 50% desconto)
- Gestão de banners/destaques
- Campanhas/recompensas
- Logs e auditoria
- Feature flags (activar/desactivar sem redeploy)
